# ASISTENCIA COMPUTACIÓN

Sistema web de registro de asistencia mediante códigos QR para la Sala de Computación del Colegio Providencia.

## Uso

1. Abrir `index.html` mediante GitHub Pages o un servidor HTTPS.
2. Autorizar el acceso a la cámara.
3. Escanear el código QR.
4. El sistema registra identificación, fecha y hora en el almacenamiento local del navegador.

## Publicación

En GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

La cámara requiere un contexto seguro (HTTPS), por lo que GitHub Pages es apropiado para el lector QR.
